# 🌸 Kurefy - J-Pop & Multi-Genre Music Station

**Kurefy** è una splendida piattaforma di streaming musicale web caratterizzata da un'estetica rilassante basata sui toni del beige e del crema (Cream/Beige Aesthetic). Permette agli utenti di esplorare e ascoltare istantaneamente le anteprime dei brani più caldi del momento divisi per categorie, con un focus speciale sul **J-Pop** e sulle sigle degli anime.

---

## ✨ Funzionalità Principali

* **⚡ Zero Setup & Zero Login:** Non richiede account Premium, token in scadenza o registrazioni. Funziona all'istante sia per te che per i tuoi visitatori.
* **🎵 Multi-Categoria in Real-Time:** Esplora le classifiche dei brani più ascoltati per ben 6 generi diversi (**J-Pop, Rap, Jazz, Classica, Rock, Pop**) cambiando scheda con un click, senza ricaricare la pagina.
* **🎛️ Player Integrato Completo:** Include una barra di riproduzione fissa in basso con controlli per Play/Pausa, traccia precedente (⏮️), traccia successiva (⏭️) e uno slider per la regolazione del volume.
* **🔄 Autoplay Continuo:** Quando un'anteprima termina, il player passa automaticamente alla canzone successiva in classifica.
* **📱 Design Responsivo & Scannabile:** Layout moderno con sidebar fissa e griglia di card flessibile, ottimizzato per schermi desktop e dispositivi mobili.

## 🚀 Tecnologie Utilizzate

Il progetto è interamente **statico**, il che lo rende perfetto, leggero e veloce per essere ospitato gratuitamente su **GitHub Pages**:

* **HTML5** – Struttura semantica della pagina e gestione audio nativa.
* **CSS3** – Layout flessibile (Flexbox e CSS Grid) con design minimalista e variabili personalizzate.
* **JavaScript (ES6+)** – Gestione dei cambi di categoria, chiamate asincrone (`Fetch API`) all'API pubblica di iTunes, e logica di controllo del player musicale.

## 📦 Come Installarlo in Locale

Se vuoi testarlo sul tuo computer o modificarlo:

1.  Clona questo repository sul tuo computer:
    ```bash
    git clone [https://github.com/IL_TUO_CONTENUTO/kurefy.git](https://github.com/IL_TUO_CONTENUTO/kurefy.git)
    ```
2.  Rinomina il file principale da `index.php` a `index.html` (se non lo hai già fatto).
3.  Apri direttamente il file `index.html` in un qualsiasi browser moderno (Chrome, Edge, Safari, Firefox).
